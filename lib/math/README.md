# Math

Number theory, modular arithmetic and miscellaneous math.

| Folder | |
|---|---|
| [`mint/`](mint/README.md) | modular integer `mint`, `ncr` with mint, plain `mod_*` helpers and prime-modulus inverse |
| [`number_theory/`](number_theory/README.md) | extended gcd / CRT, φ, μ, factorization, sieves, primality and `ncr` helpers |
| [`miscellaneous/`](miscellaneous/README.md) | exponentiation, divisors, floor/ceil blocks, bigint, gcd / lcm and small counting formulas |
